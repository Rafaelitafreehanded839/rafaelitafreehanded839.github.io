# Amirreza Asadi Academic Website

A single-file academic website for GitHub Pages.

## Publish it

1. Open your `aasad009.github.io` repository.
2. Replace the current `index.html` with the included `index.html`.
3. Commit directly to `main`.
4. Wait about one minute and refresh `https://aasad009.github.io`.

## Personalize before launch

Search inside `index.html` for:

- `Add DOI`
- `Add LinkedIn`
- `Add Google Scholar`
- `cv.pdf`

Replace those placeholders with your real links.

## Add your CV

Upload your CV to the repository with the exact filename:

`cv.pdf`

The existing **Download CV** button will then work automatically.

## Optional next files

Later, add:

- `sitemap.xml`
- `robots.txt`
- `favicon.ico`
- a professional headshot
- individual project pages
- a custom domain

## Custom domain

After buying a domain, enter it under:

`Repository → Settings → Pages → Custom domain`
