You can use it for:

## 🔍 How to Use ApexPlant AI

The interface is simple. You see a search bar and a main area.

### Ask a Question

Type your question in plain English. For example:

- "What is the maximum pressure for Reactor 4?"
- "Show me the safety procedures for shutdown."
- "When was the last calibration on Pump 7A?"

Press **Enter** or click the search icon.

### Read the Answer

The AI shows you an answer with numbered citations. Each citation links to the source document.

### Verify Sources

Click any citation number. The source document opens in a new tab. You can check the exact text.

### Refine Your Search

If the answer is not specific enough, ask a follow-up question. For example:

- "Show me the exact paragraph."
- "Give me a shorter version."
- "Compare this with the 2023 update."

## 🧩 Troubleshooting

### The installer does not start

- Make sure you have administrator rights on your computer.
- Try right-clicking the installer and selecting **"Run as administrator"**.
- Check if your antivirus is blocking the file. If so, add an exception.

### The program does not open in my browser

- Close all browser windows and restart the application.
- Make sure your browser is up to date (Chrome, Edge, or Firefox).
- Try clearing your browser cache and cookies.

### Search results are slow

- Close other programs that use a lot of memory.
- Make sure your computer meets the recommended requirements.
- Restart the application.

### I see a blank page

- Press **F5** to refresh the page.
- Check that your internet connection is working.
- Restart the program from the Start menu.
